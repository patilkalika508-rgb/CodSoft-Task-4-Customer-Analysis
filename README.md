# Customer Data Analysis

## Project Overview

This project focuses on analyzing customer data using Python to understand purchasing behavior, customer patterns, and valuable customer groups.

## What I Worked On

Analyzed customer purchasing behavior and segmented customers based on age, location, and buying patterns. Explored customer orders, quantities, and total sales to identify valuable customer groups and generate useful business insights.

## Key Takeaway

Learned how customer data analysis helps businesses understand their customers and make better marketing decisions.

## Technologies Used

- Python
- Pandas
- Matplotlib
- VS Code

## Project Files

- `task4.py` – Python code for customer data analysis.
- `cleaned_data/sales_cleaned.csv` – Cleaned dataset used for analysis.
- `customer_analysis.csv` – Analyzed customer data generated by the project.
